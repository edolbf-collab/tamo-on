# Auditoria de identidade — Build 140

Critérios do pacote atual:
- arquivos históricos não integram mais o pacote de produção;
- nomes de arquivos operacionais usam Tâmo On ou nomes neutros;
- imagens de marca e ícones vêm do kit oficial v1.1;
- manifestos e service worker apontam apenas para os ativos atuais;
- notificações usam o nome Tâmo On;
- prefixos de frontend usam `TAMOON` / `tamoon`;
- o pacote não renomeia objetos funcionais de banco apenas por aparência.
